qorder - cheatsheet demo

Ține-l deschis pe ecran. IP-ul WiFi îl afișează scriptul la pornire.

Pornire

bash demo.sh # in-memory (implicit, pentru patron) USE_DB=1 bash demo.sh # cu Postgres (persistență + cifre reale operator)

Oprești cu Ctrl+C. Deschide linkurile în Chrome/Safari, cu http:// în față, nu în căutare.

Ordinea la demo

1. Deschide ospătar + patron pe laptop (2 tab-uri). 2. Telefon /#/t/7: comandă, confirmă. La ospătar: Confirmă -> Gata -> Livrat. 3. Arată butonul de trimitere reparat. 4. /#/me (OTP 000000): comandă ~100 lei, arată puncte + chip, folosește recompensa, validează la ospătar. 5. /#/owner: încasări, medie, top produse, grafice.

Operator (doar pentru tine, din laptop)

curl -H "Authorization: Bearer demo-operator" http://<IP>:8080/platform/metrics

Întoarce localuri + comenzi + utilizatori per local. Gol pe in-memory, cu cifre reale pe USE_DB=1.

Cei doi timpi de pe dashboardul de patron

Timp mediu preluare

De când clientul trimite comanda până când ospătarul o confirmă. Cât de repede sare personalul pe comenzi.

Timp mediu livrare la masă

De când băutura e gata până când ajunge la masă. Gap-ul bar -> masă, separat de preparare.

Ctrl+C # oprește app + BFF docker compose -f bff/docker-compose.yml down # doar dacă ai folosit USE_DB=1
